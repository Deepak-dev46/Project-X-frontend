# Project-48 Frontend

Premium enterprise application engineering workspace built with Next.js App Router, React, JavaScript and custom CSS.

## Requirements
- Node.js 18.17+
- npm 9+

## Run locally
```bash
npm install
npm run dev
```
Open http://localhost:3000

## Production build
```bash
npm run build
npm start
```

## Current implementation
- Responsive enterprise application shell
- Pure White × Violet Aura design system
- Dashboard overview with metric cards
- Engineering activity chart (Recharts)
- Recent activity feed
- Application portfolio table
- Platform health and AI insight panels
- Navigation structure for all 16 platform modules

## Next implementation steps
1. Build the shared module page framework and route pages.
